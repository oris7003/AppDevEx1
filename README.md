A responsive digital business card built using **HTML5 and CSS3 only** (no JavaScript).

## Features
- **Pure CSS Theme Toggle:** Switch between Dark and Light mode using a hidden checkbox and the `:checked` pseudo-class with CSS custom properties (variables), without JavaScript.
- **Responsive Layout:** Adapts smoothly across mobile, tablet, and desktop viewports using CSS Flexbox and Grid.
- **Semantic HTML5:** Structured using standard semantic elements (`header`, `main`, `section`, `article`, `nav`, `footer`).
- **Personal Card:** Includes an SVG profile avatar, short bio, tech skills, featured projects, and contact buttons (phone, email, GitHub, and LinkedIn).

## Project Structure
- `index.html` - Semantic HTML markup and content
- `styles.css` - Stylesheet, custom properties, theme definitions, and media queries
- `assets/` - Vector graphics (`avatar.svg`, `favicon.svg`)

## How to Run
Open `index.html` directly in any modern web browser, or serve it locally using VS Code's Live Server extension.
